# FAQ

## Is BOUNDARY equivalent to HTTP 404?

No.

HTTP status codes are defined by RFC 9110.  
BOUNDARY is a DebugShrine classification.  
The two concepts are independent.

## Is GOVERNANCE equivalent to HTTP 500?

No.

HTTP status codes and DebugShrine classifications belong to different domains.

## Does GET imply NORMAL?

No. HTTP methods are not classification inputs.

## Does POST imply GOVERNANCE?

No. HTTP methods are not classification inputs.

## Is RouteError an HTTP routing result?

No.

RouteError is `ExpectedGate != ActualGate` on a DebugShrine record.  
HTTP routing and RouteError are independent.

## Does this repository claim RFC 9110 compliance?

No.

Any RFC 9110 crosswalk is informational only.  
Compliance statements belong to HTTP implementations, not to DebugShrine classifications.

## Why provide the crosswalk?

To prevent terminology confusion.

The crosswalk explains boundaries. It does not define equivalence.

## If something is missing from GitHub, does that mean it does not exist?

No.

Absence from this repository means it is not part of the *published* contract.  
It may be private, unpublished, or out of scope. Do not read absence as nonexistence.

## Is O-mikuji fortune telling?

No.

O-mikuji is a narrative view of a snapshot, not a prediction.  
Do not use it for personal, financial, legal, medical, or operational decisions.

## Is Kenneth a specification?

No.

Character / persona talk is user narrative completion (metric N3).  
It is not part of the public contract.
